# Gemini Review 프로젝트 지침

## Claude 답변 가이드라인

**중요: 모든 답변 전에 반드시 신중하게 생각하고 답변하세요.**

### 답변 원칙
1. 질문을 정확히 이해했는지 검토
2. 답변이 정확하고 완전한지 확인
3. 코드나 기술적 내용의 경우 논리적 오류가 없는지 검증
4. 사용자의 의도와 맥락을 고려한 답변인지 점검

### 프로젝트 정보
- GitHub Issues 및 워크플로 자동화 도구
- 클로드와 Gemini API를 활용한 코드 리뷰 시스템
- Python 기반 프로젝트

### 주의사항
- 답변하기 전 충분히 생각하고 검토할 것
- 불확실한 내용은 명확히 표시
- 코드 수정 시 기존 구조와 컨벤션 준수
